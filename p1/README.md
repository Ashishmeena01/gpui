# GPUI Counter

A small desktop counter built with [GPUI](https://github.com/zed-industries/zed/tree/main/crates/gpui).

The window displays the current value and provides controls to increment, decrement, or reset it.

## Run

From this directory, start the app with:

```sh
cargo run
```

## Controls

- **Increment** adds one to the current value.
- **Decrement** subtracts one; negative values are allowed.
- **Reset** returns the value to zero.
